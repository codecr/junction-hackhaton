Cover re:Invent as a team without sharing accounts.

Your squad picks sessions as usual. Junction lays everyone’s day side by side, shows what nobody covers, where two of you planned the same session, and which walks between venues do not fit. Each person keeps their own sign-in and their own schedule.

How it works

Everyone runs Junction on their own laptop

You sign in with your own AWS Builder ID. Junction reads and changes only your schedule, and your sign-in never leaves your machine.

The squad shares picks, not accounts

Each member publishes a signed list of session codes and priorities. No titles, no email, no tokens. The squad server only passes these lists around, and file exchange works without it.

Every laptop reaches the same suggestions

The same rules run on the same picks, so everyone sees the same proposals: swap to a repeat, drop a duplicate, take a session nobody covers. You accept or decline each one yourself.

Junction is an unofficial community project built for the re:Invent Event Catalog API Hackathon. It is not affiliated with or endorsed by Amazon Web Services.

The demo uses invented sessions and people. It makes no network requests.
